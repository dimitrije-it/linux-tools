# Linux Tools & Automation Suite

A collection of native Bash scripts and system administration utilities designed for Linux environments. Built for automating routine maintenance, monitoring system health, and managing server infrastructure through the command line.

## Tools Included

- **`resource_logger.sh`**: Automatically tracks and logs system resource utilization (CPU, memory, and disk space) with precise timestamps for performance monitoring.
